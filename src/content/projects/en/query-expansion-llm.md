## Context

On assignment at **INA** (French National Audiovisual Institute) for TATA Consultancy Services, I built the query expansion module of the document search end to end.

It is also the topic of my master's thesis (M2 MIAGE, Université Paris-Saclay): LLM-based query rewriting for document retrieval.

## The problem

A search query is often short, and its words are not always the ones used in the documents you are looking for. Query expansion rewrites and enriches the query before it is sent to the engine, so that relevant documents the raw query would have missed can be found.

## What I built

- The whole module, from the query typed by the user to the enriched query passed to the search engine.
- The expansion is generated by an LLM, **Qwen served by Ollama**.
- A comparison between raw and expanded queries to measure what the module brings.

## Result

On the cases tested, expanded queries return more relevant results than raw queries.
