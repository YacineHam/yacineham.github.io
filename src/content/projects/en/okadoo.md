## Context

At Maystro Delivery, I designed and shipped the MVP of **OKADOO**, an e-commerce marketplace that later became an independent startup — from initial design to production in under 10 months.

## What I built

- **RESTful APIs with Django REST Framework**: advanced serializers, custom permissions and generic views for a modular, maintainable architecture.
- **Product search with Algolia**: smart suggestions and instant results, with a measurable impact on user engagement.
- **Async operations with Celery**: email delivery, automatic invoice generation and scheduled tasks.
- **Customized Django Admin** to automate operational workflows and reduce the support team's manual workload.

## Infrastructure & results

- Managed the production GCP environment and supervised CI/CD pipelines for continuous, zero-downtime deployments.
- **−30% infrastructure costs** through instance rightsizing and database query optimization.

## Stack

Python · Django · Django REST Framework · PostgreSQL · Celery · Algolia · GCP (Cloud Run, Cloud SQL) · Docker
