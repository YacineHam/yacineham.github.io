## Context

At Maystro Delivery, I designed and shipped the MVP of **OKADOO**, an e-commerce marketplace that became an independent startup, from design to production in under 10 months.

## What I built

- **REST APIs on Django REST Framework**, with custom permissions and a modular architecture based on generic views.
- **Product search with Algolia**, with suggestions and instant results.
- **Celery** for sending emails, generating invoices automatically and running scheduled tasks.
- **Customized Django Admin** to automate the support team's operational workflows.

## Infrastructure

- Managed production GCP environments and CI/CD pipelines, with zero-downtime deployments, monitored with Cloud Monitoring / Logging.
- Optimized GCP resource usage: instance rightsizing and database queries.

## Stack

Python · Django · Django REST Framework · Celery · Algolia · GCP · CI/CD
