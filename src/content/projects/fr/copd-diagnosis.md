## Contexte

Projet de recherche mené à l'**URD-SE** (Unité de Recherche et Développement, Sidi Bel Abbès) : une application web d'aide au diagnostic des maladies respiratoires (BPCO) à partir d'enregistrements audio.

## Ce que j'ai construit

- **Pipeline ML de bout en bout** : prétraitement des fichiers audio, transformation en spectrogrammes MFCC, augmentation et normalisation des données.
- **Modèle CNN** de classification des maladies respiratoires.
- **Application web Django + React** qui restitue les résultats de diagnostic via une API REST.

## Ce que j'en ai retiré

C'est le premier projet où j'ai porté un système de machine learning jusqu'à une application utilisable.

## Stack

Python · Django · React · CNN · MFCC · API REST
